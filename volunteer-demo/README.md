# 도서관에서 살아남기 · 첫 봉사 샘플

library98의 새 인트로·튜토리얼과 자원봉사자 근무 샘플입니다. 기존 library99와 pixel-field 샘플, 사용자가 수정한 문구 파일은 수정하지 않습니다.

`play.html`을 다운로드해 최신 브라우저로 열면 실행됩니다. 인터넷 연결이나 패키지 설치가 필요하지 않습니다. WebGL2와 DecompressionStream을 지원하는 Chrome·Edge·Safari 등의 브라우저를 사용합니다.

## 샘플의 흐름

1. 책이 좋으니 도서관 일도 적성에 맞겠다는 낙관적인 주인공의 첫 방문.
2. 청구기호 순서에 관한 책 꽂기 미니게임 4문제. 책 5권 사이의 틈에 전체 청구기호가 적힌 책을 끌어 넣습니다. 숫자 → 문자 → 저자 숫자를 소수의 자릿수처럼 비교 → 마지막 문자 순서입니다. `808.3가125ㄴ`은 `808.3가55ㄴ`보다 앞입니다. 책등은 가로 두 줄로 표시합니다.
3. 책 모양 카드에서 가져갈 책을 최대 5권까지 선택 → 선택 완료 → 북카트에 담기 → 손잡이를 잡고 가까이서 밀기 → 책 꺼내기 → 서가에 꽂기. 선택 취소 시 바닥의 책은 그대로 남고, 일부만 가져간 경우 남은 책도 이어서 정리할 수 있습니다.
4. 이용자의 질문을 듣고 서가까지 안내하는 응대 연습.
5. 기기 문제를 접수해 담당 주무관에게 요청. 직원이 현장에 와서 처리하고 제자리로 돌아갑니다. 처리 초 수는 플레이어에게 표시하지 않습니다.
6. “나중에 여기서 일해보고 싶다”는 주인공과, 지친 표정으로 의미심장하게 바라보는 금발 계약직 선생님의 마지막 대화.
7. 버튼을 눌러 09:00~13:00, 실제 진행 시간 180초의 봉사자 근무 시작. 최대 5일의 봉사 활동 후 주말계약직 지원 장면으로 샘플을 마칩니다. 계약직 이후의 실제 업무 게임은 이번 샘플 범위에 포함되지 않습니다.

## 인물과 이후 이야기

- 주인공: 기존 갈색 단발·안경 디자인. 필드에 한 명만 배치하고, 대화 이미지는 걱정 없는 기대와 자신감이 드러나는 표정으로 새로 제작했습니다. 책이 1~2권이면 한 손으로, 3~5권이면 두 팔로 안는 별도 도트를 사용하며 각 자세에 네 방향 걷기 프레임이 있습니다.
- 계약직 선생님: 앞머리 없는 금발 장발 펌, 녹색 카디건. 필드 걷기 12프레임, 대화용 지친 표정·의미심장한 표정.
- 주무관: 검은 낮은 묶음머리와 남색 조끼. 봉사자·계약직이 해결할 수 없는 문제를 수습합니다. 필드 걷기 12프레임과 별도 상반신 일러스트.
- 응대 연습용 아이와 중년 이용자: 각자의 필드 외형과 맞는 상반신 일러스트.

직급별 시놉시스는 `story.js`의 `CAREER_ARC`에 기록했습니다. 봉사자는 적은 업무 덕분에 희망이 커지고, 계약직 시기에도 한정된 책임 속에서 사서를 꿈꿉니다. 최종적으로 주무관이 되면 그동안 요청하던 수습과 업무를 직접 감당하며 동태눈이 되는 방향입니다.

## 규칙과 권한

봉사자는 대출·반납 처리를 할 수 없습니다. 일상적인 데스크 문의는 계약직에게, 기기 고장처럼 담당자 권한이 필요한 문제는 주무관에게 전달합니다. 주무관은 기본 위치에서 대기하다 요청된 곳으로 이동해, 도착 후 내부적으로 2초를 처리한 뒤 돌아옵니다. 동일 사건은 한 번만 접수·해결하며, 담당자가 이동하는 동안 추가 경고가 생기지 않습니다.

오늘 잘못된 응대 3회 또는 어제 2회 이상·오늘 2회 이상이면 즉시 봉사 참여가 종료됩니다. 같은 사건은 중복 기록하지 않습니다. 날짜가 바뀌면 오늘의 횟수는 초기화하고 전날 기록은 보존합니다. 경고는 우측 상단의 단일 아이콘으로 표시하고, 계약직·주무관용 민원 5종 표시는 봉사자 단계에서 사용하지 않습니다.

하트 5개는 표시하되, 아직 정하지 않은 HP 감소 규칙은 추가하지 않았습니다. 퇴근 시 미배가 책은 목표 미완료로 표시하고, 이를 즉시 해고나 응대 실수로 바꾸는 추가 조건은 넣지 않았습니다. 본근무의 이용자 수·책 수 등은 샘플 조정값입니다. 대화와 배가 창, 다른 탭을 보는 동안은 근무 시간이 멈추는 방식으로 구현했습니다.

저장 키는 `library98-volunteer-demo-v1`이며 기존 게임 저장과 분리되어 있습니다. 재접속 시 이어하기·새로 시작을 선택할 수 있습니다. 샘플 검수 모드의 진행은 저장 기록을 변경하지 않습니다.

## 조작과 검수

- WASD·방향키 또는 바닥 클릭: 이동
- E 또는 인물·북카트 클릭: 가까우면 상호작용, 멀면 접근 후 상호작용
- C 또는 화면 버튼: 카트 연결·분리
- 책 확인: 손·카트의 책 제목과 전체 청구기호
- 마우스 오른쪽 드래그: 회전 / 휠: 확대
- 모바일: 왼쪽 조이스틱·오른쪽 확인 버튼. 세로·가로 화면 대응.
- 상단 ‘샘플 검수’: 배가·카트·응대·호출·마지막 대사·근무·경고 판정으로 바로 이동. ‘검수 끝내기’로 원래 상태 복귀.

`node tests/flow.cjs`는 실제 게임 핸들러와 경로 탐색을 사용하는 DOM 대역에서 튜토리얼 전체 진행, 5권 선택 제한과 취소, 카트와 사서의 간격, 10개 서가까지의 카트 경로, 이전 배치 저장 기록의 보정, 이용자 안내, 직원 이동·처리·복귀, 연습/본근무 통계 분리, 날짜 전환, 경고와 검수 복귀를 검사합니다.

서가는 3개씩 세 줄, 남은 900 역사 서가는 오른쪽 벽에 배치했습니다. 눈에 보이는 모델과 충돌 영역을 함께 옮겼으며, 카트 경로는 사서와 카트가 모두 통과할 수 있는지 확인합니다. 장애물 없는 구간은 직선으로 걷고, 장애물을 돌아가는 구간도 충돌을 확인하며 불필요한 꺾임을 줄입니다. 북카트의 화면상 위치를 클릭하면 카트 앞까지 접근합니다. 북카트 옆에는 담긴 책의 제목과 청구기호를 표시하고 배경만 80% 불투명하게 합니다. 목록이 길면 스크롤할 수 있습니다.

대화 이미지는 인물마다 실제 그림 경계에 맞게 표시합니다. 계약직 선생님과 주무관의 위쪽에 다른 인물이 섞이던 문제를 수정했습니다. 직원 두 명은 화면 기준 데스크 앞쪽에 서서 뒷모습을 보이며 키보드와 모니터를 바라봅니다. 모니터와 키보드도 그 방향으로 배치했습니다.

배가 미니게임의 책등에는 제본 굴곡, 금박 장식, 종이 가장자리와 청구기호 라벨을 넣었습니다. 청구기호는 가로 두 줄로 읽을 수 있고, 현재 비교하는 숫자나 문자만 굵게 표시합니다. 저자 숫자 연습에서는 첫 번째 자릿수만 강조합니다.

Chromium에서 모바일 세로 390×844, 가로 844×390, PC 1280×800 화면으로 인트로·계약직/주무관 대화 이미지·책 선택·카트 목록을 검사했습니다. 모바일은 터치 입력을 사용하고 조이스틱·확인·소지품 버튼이 화면 안에 들어오는지 확인했습니다. `assets/preview-overview.png`와 `assets/preview-follow.png`는 이번 수정본의 실제 브라우저 캡처입니다. 개별 기기의 Safari·Chrome 실기기 검수와는 구분합니다.

## 파일

- `story.js`: 이번 샘플의 신규 대사·시놉시스
- `rules.js`: 청구기호·시계·경고 규칙
- `game.js`: 튜토리얼·근무·호출·저장·검수 흐름
- `style.css`: 화면·카드·미니게임·모바일 배치
- `assets/`: 사용한 이미지, 스프라이트 메타데이터, 환경·카트·책 모델
- `package.py`: 오프라인 HTML과 소스 ZIP 생성
- `build-assets.py`: 기존 `../pixel-field/models/library-field.blend`를 읽어 별도 환경·움직이는 카트·책 GLB 생성. 원본 Blender 파일은 변경하지 않습니다.
- `prepare-carry-sprites.py`: 생성된 책 운반 도트의 네 방향·세 프레임 경계를 분석해 메타데이터를 생성. 이미지 픽셀은 변경하지 않습니다.

이미지는 image_gen으로 제작했으며 원본 생성 파일을 보존했습니다. 스프라이트 메타데이터만 인덱싱해 사용합니다.
