# library98 · 인트로와 시놉시스 수정 기준

사용자의 최신 피드백을 반영한 2차 기준입니다. 앞선 1차 설계안과 충돌하는 부분은 아래 내용을 따릅니다.

## 이야기의 핵심

주인공은 걱정과 두려움 없이 “책을 좋아하니까 도서관 일이 적성에 맞고 재밌을 것”이라는 환상을 품고 시작합니다. 봉사자 때는 할 일이 적어 희망이 더 커집니다. 계약직을 거치며 진상과 여러 문제를 만나 슬픈 날도 있지만, 업무와 책임은 주무관보다 제한되어 있어 정식 사서를 계속 꿈꿉니다. 최종적으로 주무관이 되어 그동안 남이 처리하던 문제와 온갖 업무를 직접 떠안고 동태눈이 됩니다. 플레이어가 사서의 업무량과 진상 응대의 고됨을 체감하는 것이 중심입니다.

## 담당자 호출의 의미

주무관은 봉사자·계약직이 처리할 수 없는 문제를 수습하는 담당입니다. 호출을 받으면 현장으로 와서 처리한 뒤 원래 위치로 돌아갑니다. 주인공이 나중에 주무관이 되었을 때 직접 맡을 일의 복선입니다. 봉사자에게 처리 소요 시간 같은 내부 구현 수치를 설명하지 않습니다.

## 튜토리얼 순서

1. 낙관적인 주인공이 첫 봉사를 시작합니다.
2. 책 꽂는 방법부터 배웁니다. 전체 청구기호의 숫자 → 문자 → 숫자 → 문자를 순서대로 비교하는 드래그 미니게임 4문제를 모두 맞힙니다. 문자 뒤 숫자는 소수의 자릿수처럼 비교하며, `808.3가125ㄴ`이 `808.3가55ㄴ`보다 앞입니다.
3. 북카트에 책을 담고, 연결해 옮기고, 꺼내서 꽂는 방법을 배웁니다.
4. 이용자에게 말을 듣고 안내하거나 담당자에게 연결하는 ‘이용자 응대’를 배웁니다.
5. 어려운 문제를 담당 선생님께 요청하고, 선생님이 와서 처리한 뒤 돌아가는 모습을 봅니다.
6. 주인공은 “역시 도서관이 나와 잘 맞는다, 나중에 여기서 일하고 싶다”고 말합니다. 계약직 선생님은 지친 표정과 의미심장한 눈빛·짧은 말로 반응합니다.
7. 1일차 시작 버튼으로 09:00~13:00의 180초 본근무를 시작합니다.

## 계약직 선생님의 디자인

여성, 금발 장발, 앞머리 없이 이마를 드러내고 펌이 있는 머리입니다. 새 필드용 도트와 별도의 대화용 상반신 일러스트를 사용합니다. 피곤한 기본 표정과 말뜻을 쉽게 알 수 없는 눈빛의 표정을 구분합니다. 주인공 외형을 복제하지 않습니다.
