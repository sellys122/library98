# library98 · 도서관에서 살아남기

오래된 갈색 도서관을 배경으로 한 카드 선택형 생존 게임 샘플입니다.

## 샘플 규칙

- HP는 5개이며 다음날에도 유지됩니다. 0이면 해고됩니다.
- 대면·전화·게시판·국민신문고·상급자 민원 5종을 표시합니다.
- 같은 민원 2건이면 해당 아이콘이 빨간불로 바뀝니다. 3종류가 빨간불이면 즉시 해고됩니다.
- 민원은 다음날 초기화됩니다.
- 하루 4개 에피소드, 5일 생존마다 승진합니다.
- 자원봉사자 → 주말계약직 → 개관시간연장 계약직 → 평일계약직 → 신규 주무관.
- 마지막 승진까지 4번의 5일 근무를 거칩니다. HP를 유지하며 계속합니다.

샘플 제작 중입니다. 실행 파일과 GitHub Pages 안내를 함께 추가합니다.
